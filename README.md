## Tic-tac-toe

This is a two-player, console-based tic-tac-toe game. Players take turns
entering a row and column; the first player to win two rounds wins the game.
Drawn rounds do not count toward either player's score.

Build and run from this directory with:

```sh
g++ -std=c++11 -Wall -Wextra -Wpedantic Grid.cpp Player.cpp TicTacToe.cpp main.cpp -o tic-tac-toe
./tic-tac-toe
```
